# גשר קוד — אפליקציה / WhatsApp → שינוי קוד אוטומטי

## למי זה מיועד

אתה כבר משתמש ב**צ'אט הסוכן באפליקציה** (רוב הזמן) או ב-**WhatsApp**.  
שניהם מחוברים לאותו מערכת.

- **הודעה רגילה** (בלי קידומת) → סוכן Gemini כרגיל (משימות, עושר, Gmail וכו').
- **הודעה עם `קוד:` או `/dev`** → מושק סוכן Cursor שכותב קוד ב-GitHub ופותח PR.

אין קובץ לפתוח, אין Cursor על המחשב, אין פעולה ידנית ב-GitHub.

---

## איך שולחים

### מאפליקציה (מומלץ)

בצ'אט הסוכן באפליקציה:

```
קוד: תקן את מסך המשימות במובייל
```

או:

```
/dev הוסף לוג בנקודת הכניסה ל-API
```

(`/dev` לא רגיש לרישיות.)

### מ-WhatsApp

אותו פורמט, מאותו מספר מורשה:

```
קוד: הוסף שורה ל-README
```

---

## מה קורה אחרי ששלחת

1. **מיד** — תשובה בעברית: אישור, קישור לסוכן ב-Cursor, מזהה משימה, כמה השקות נשארו היום.
2. **ברקע** — סוכן Cursor עובד על הריפו `MySelf`, פותח PR (בדרך כלל מסניף `cursor/...`).
3. **אוטומטית** — GitHub מריץ בדיקות (`verify`). אם עברו — מיזוג ל-`main`.
4. **פריסה** — Vercel מעלה גרסה חדשה ל-production.

לא מחכים ל-TestFlight / EAS iOS (מכסה חינמית מוגבלת).

```
אתה (אפליקציה / WhatsApp)
        ↓
   "קוד: ..."
        ↓
   השרת (Vercel)
        ↓
   סוכן Cursor → PR ב-GitHub
        ↓
   בדיקות ירוקות → merge ל-main
        ↓
   אתר / אפליקציה מעודכנים
```

## הגדרה חד-פעמית (מנהל)

1. מיזוג הקוד ל-`main` (כולל מיגרציה DB).
2. [Cursor Dashboard → API Keys](https://cursor.com/dashboard/api) — ליצור מפתח.
3. Vercel → Production → Environment Variables → `CURSOR_API_KEY` = המפתח.
4. **Redeploy** ב-Vercel (חובה אחרי הוספת המשתנה).
5. בדיקה: `קוד: הוסף שורה ל-README` מ-WhatsApp או מהאפליקציה.

אם חסר `CURSOR_API_KEY` — תקבל: «גשר הקוד לא מוגדר».
